# AGY Assistant — ИИ-помощник прямо в Minecraft (1.21.1 NeoForge)

Клиентский мод: внутриигровой чат с ИИ, который видит твой мир. Прикрепи блок, моба, предмет из инвентаря или скриншот — и спроси что угодно по игре. Работает в одиночке и на любых серверах, на сервер ставить ничего не нужно.

---

## Быстрый старт — 3 шага

1. **Установи мод** (см. [Установка](#установка)).
2. Зайди в мир и нажми **`G`** — откроется чат. При первом запуске он сам подскажет, что делать дальше.
3. Нажми **`Config`** в правом верхнем углу чата:
   - **Сервис** — выбери, где брать ИИ: `Gemini` / `OpenRouter` / `Groq` / `Ollama`. Base URL и модель подставятся сами.
   - **Получить ключ** — откроется страница выбранного сервиса, где выдать себе ключ.
   - Вставь ключ в поле **API-ключ** → **Сохранить**.
   - **Проверить подключение** — мод отправит реальный тестовый запрос каждой модели цепочки и скажет по-русски, всё ли ок: `OK — сервис отвечает (задержка N мс)` либо понятную причину ошибки (неверный ключ, блокировка по региону, лимит, модель не найдена).

Всё. Дальше просто спрашивай.

---

## Что умеет

- **Захват цели в мире (`Alt + G`):** блоки (ID, мод, свойства, теги, NBT), сущности (ID, HP, теги), игроки (ник, броня, пинг). Пусто под прицелом — подхватит предмет из руки.
- **Захват из GUI (`Alt + G` в инвентаре / сундуке / JEI / EMI):** ID, название, tooltip, Data Components 1.21.1.
- **Скриншоты:** чекбокс `Attach screenshot` или кнопка `Shot` — сжимается в фоне, без фризов.
- **Кликабельные карточки:** ИИ упоминает `minecraft:wheat` или `create:mechanical_press` — под ответом появляются карточки с иконкой и tooltip:
  - **ЛКМ** — рецепт в JEI/EMI (нет их — скопировать ID), **ПКМ** — использования, **СКМ** — вики.
  - **Shift+ЛКМ** — прикрепить предмет в контекст нового вопроса.
  - Если ИИ написал ID с опечаткой или из старой версии — мод покажет карточку ближайшего реального предмета и честно пометит это в tooltip. Совсем выдуманные ID остаются жёлтым кодом.
- **Работа в фоне:** закрыл чат (`Esc`) — ответ продолжит генерироваться, а когда придёт, справа снизу выскочит уведомление в стиле мода (со звуком). Никакого «сиди и жди».
- **Очередь вопросов:** можно писать следующие, пока ИИ думает — уйдут по порядку.
- **Запасные модели (fallback):** если основная модель упала или упёрлась в лимит, OpenRouter автоматически переключится на следующую из списка. Списком удобно управлять в настройках: «+ Добавить из списка», `×` убирает.
- **Приватность:** в настройках можно запретить отправку координат мира и скриншотов — мод срежет их на уровне запроса.
- **Прокси для API:** можно пустить через VPN только запросы к нейронке, не трогая трафик игры (см. [Если что-то не работает](#если-что-то-не-работает)).

## Горячие клавиши

Меняются в стандартных настройках управления (категория **Antigravity Assistant**):

| Клавиша | Действие |
| :--- | :--- |
| `G` | Открыть чат |
| `Alt + G` | Захватить блок / моба / игрока / предмет (в мире или под курсором в GUI) и открыть чат |
| `Enter` | Отправить сообщение |
| `Esc` | Закрыть окно (генерация продолжится в фоне) |

## Установка

### Одна команда в PowerShell
```powershell
irm https://raw.githubusercontent.com/pixiemays/agy-assistant-mc/main/install.ps1 | iex
```
Скрипт сам найдёт сборки в `ElyPrismLauncher`, `PrismLauncher`, `ModrinthApp`, `CurseForge`, `ATLauncher` и `.minecraft`, скачает мод и зависимости с Releases/Modrinth.

### Вручную с GitHub Releases
1. Скачай [последний Release](https://github.com/pixiemays/agy-assistant-mc/releases/latest):
   - `agy-assistant-direct.zip` (~215 КБ) — только мод, без `.exe` (Gemini / OpenRouter / Groq / Ollama / любой OpenAI-совместимый API);
   - `agy-assistant-full-windows.zip` (~65 МБ) — полный комплект с `agy-bridge.exe` (для Antigravity / OpenCode).
2. Распакуй и запусти `install.bat` — сам поставит мод, зависимости и предложит режим.

### Совсем вручную
В `mods/` положи `agyassistant-0.2.0.jar`, `kotlinforforge-neoforge` (5.x) и `owo-lib-neoforge` (0.12.x). Для Antigravity/OpenCode дополнительно — `agy-bridge.exe` в `config/agyassistant/`.

## Сервисы: где взять ключ

Выбираются кнопкой **Сервис** в настройках, URL и модель подставляются автоматически:

| Сервис | Где ключ | Заметки |
| :--- | :--- | :--- |
| **Gemini (Google AI Studio)** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | Бесплатный Flash. Может быть заблокирован по региону — см. ниже про VPN/прокси. |
| **OpenRouter** | [openrouter.ai/settings/keys](https://openrouter.ai/settings/keys) | Модели с суффиксом `:free`. ⚠️ Для `:free` в настройках аккаунта (**Settings → Privacy**) должно быть разрешено логирование промптов, иначе `404 No endpoints found` — мод сам подскажет, если наткнётся. |
| **Groq** | [console.groq.com/keys](https://console.groq.com/keys) | Очень быстрый бесплатный тир. |
| **Ollama** | ключ не нужен | Поставь [Ollama](https://ollama.com) и скачай модель: `ollama pull qwen3:8b`. Работает без интернета. |

Не уверен, какую модель выбрать — жми **«Доступные модели»** в настройках: мод покажет всё, что доступно именно твоему ключу, с поиском.

**Fallback-цепочка** (OpenRouter): под полем «Модель» есть список запасных — «+ Добавить из списка», `×` убирает. «Проверить подключение» прогоняет живой запрос по каждой и ответит, кто работает, а кто нет.

## Продвинутый режим: Antigravity / OpenCode (`agy-bridge.exe`)

Для локального агента с доступом к папке сборки (читает `config/`, `kubejs/`, `logs/latest.log` — чтобы разбирать кастомные рецепты и ошибки модпака):

- `Provider: Antigravity (SDK / agy CLI)` — использует `Gemini API Key` или установленный в системе `agy.exe`;
- `Provider: OpenCode CLI (via Bridge)` — использует установленный `opencode`.
- Опция **`Read-only доступ к папке сборки`** включает этот доступ (по умолчанию выключен).
- `agy-bridge.exe` сам стартует при запуске игры и сам завершается при выходе (даже при краше).

## Гайд: VPN только для нейронки («Прокси для API»)

Если сервис ИИ заблокирован по региону (например Gemini в РФ), обычно включают VPN на всю систему — но тогда через VPN идёт и игра, пинг растёт. Поле **«Прокси для API»** решает это: через VPN уходят **только** запросы мода к нейронке, весь остальной трафик Minecraft — напрямую.

**Что нужно:** VPN-клиент с локальным HTTP-портом. Где его взять у популярных:

| Клиент | Где посмотреть порт |
| :--- | :--- |
| Clash / Clash Verge / Mihomo | Mixed Port, по умолчанию `http://127.0.0.1:7890` |
| v2rayN | HTTP-порт, по умолчанию `http://127.0.0.1:10809` (порт 10808 — это SOCKS, не подойдёт) |
| Hiddify и sing-box-обёртки | Пункт «Mixed/HTTP port» в настройках |
| Outline, чистый WireGuard | Локального HTTP-прокси нет — используй системный VPN или сплит-туннелинг в самом клиенте |

**Шаги:**
1. Запусти VPN-клиент (в Clash порт слушается всегда, «системный прокси» включать не обязательно).
2. Проверь, что порт живой, в PowerShell — должен вернуться IP VPN-сервера:
   ```powershell
   curl.exe -x http://127.0.0.1:7890 https://api.ipify.org
   ```
3. В моде: **Config → «Прокси для API»** → вставь `http://127.0.0.1:7890` → **Сохранить**.
4. **«Проверить подключение»** — должно позеленеть. Готово: нейронка через VPN, игра напрямую.

**Важно знать:**
- Поддерживается только **HTTP**-прокси (`http://...`). Clash «mixed»-порт умеет HTTP — ок; чистый SOCKS-порт java не понимает — возьми HTTP-порт клиента.
- Поле действует **только в режиме Direct API**. Antigravity/OpenCode (`agy-bridge.exe`) ходит в интернет сам — его трафик мод не проксирует, там нужен системный VPN.
- Кривой адрес или упавший клиент — мод тихо откатится на прямое соединение, а «Проверить подключение» честно покажет регионную ошибку.

## Если что-то не работает

- **`403` / ошибка handshake (регион заблокирован):** включи VPN. Не хочется гнать игру через VPN — два варианта:
  - в своём VPN-клиенте включи **сплит-туннелинг** только для домена API;
  - либо укажи в настройках поле **«Прокси для API»** — локальный HTTP-прокси VPN-клиента (Clash: `http://127.0.0.1:7890`, v2rayN: `http://127.0.0.1:10809`). Через VPN пойдёт только трафик нейронки, игра — напрямую.
- **`404 No endpoints found` у `:free`-модели:** разреши логирование промптов в аккаунте OpenRouter (**Settings → Privacy**).
- **Индикатор `Offline` в режиме моста:** проверь `config/agyassistant/agy-bridge.exe` и лог `config/agyassistant/bridge.log`. В режиме Direct API — что заполнены «Base URL», ключ и модель, и жми «Проверить подключение».
- **Скриншоты выдают ошибку:** не все модели понимают картинки — «Проверить подключение» покажет, поддерживает ли модель скриншоты. Или выбери vision-модель (например `qwen/qwen2.5-vl-72b-instruct:free`).
- **ИИ написал предмет жёлтым текстом вместо карточки:** это значит, что такого ID нет в игре — модель либо ошиблась в написании (мод покажет ближайший реальный предмет), либо его выдумала.
